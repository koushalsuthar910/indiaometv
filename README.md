# IndiaomeTV — Random 1-to-1 Video Chat

A production-style random video chat app built with **React + Vite + TypeScript + Tailwind** on the frontend and **Node + Express + TypeScript + Socket.IO** on the backend, using **WebRTC** for peer-to-peer media.

> ⚠️ **18+ only.** IndiaomeTV does not record video/audio. See `/privacy`.

## 1. Requirements
- Node.js 20+
- npm 10+
- (Optional) Docker + Docker Compose
- A browser with WebRTC support

## 2. Install

```bash
cd server && npm install && cd ..
cd client && npm install && cd ..
